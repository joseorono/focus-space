## 5. Declaración de Privacidad y Justificación de Permisos (Chrome Web Store Privacy Practices)

Cuando subas la extensión al Chrome Developer Dashboard, deberás justificar por qué requieres cada permiso de Manifest V3. Aquí tienes las justificaciones listas:

### Single Purpose Description (Propósito único)

> _"FocusSpace is a productivity extension designed to eliminate digital distractions by identifying and closing tabs, removing browsing history for user-selected distraction categories, and providing a local Pomodoro focus timer."_

---

### Permisos y Justificaciones Técnicas

| Permiso             | Justificación para el formulario de Chrome Web Store                                                                                                                                                    |
| :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`history`**       | Required to search and selectively remove browsing history entries matching distraction categories (e.g., social media, entertainment) and user-defined keywords, preventing autocomplete distractions. |
| **`tabs`**          | Required to inspect active and background tab URLs to identify distracting sites and close them when the user clicks 'Clean Session' or during an active Pomodoro focus sprint.                         |
| **`browsingData`**  | Required to purge history and transient site data for specific distraction categories selected by the user.                                                                                             |
| **`storage`**       | Required to store user settings, enabled categories, custom keywords, whitelisted domains, and Pomodoro timer status locally on the user's device.                                                      |
| **`alarms`**        | Required to run precise background intervals for the Pomodoro timer and scheduled focus reminder notifications.                                                                                         |
| **`notifications`** | Required to send gentle browser notifications when a Pomodoro focus or break session finishes, or when a distraction limit is triggered.                                                                |
| **`bookmarks`**     | Optional utility permission used to verify if distracting links originate from stored bookmarks.                                                                                                        |
| **`downloads`**     | Required only if cleaning temporary file download logs associated with distraction sessions when explicitly requested.                                                                                  |

---

### Declaraciones de Datos (Data Usage & Privacy)

- **Does this extension collect or transmit personal data?** `No`
- **Does it sell data to third parties?** `No`
- **Does it use data for unrelated purposes or creditworthiness?** `No`
- **Hosting/Server:** `No external server communication. All logic runs 100% locally via client-side JavaScript in the browser.`
