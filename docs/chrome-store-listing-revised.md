## 5. Declaración de Privacidad y Justificación de Permisos (CWS Privacy Practices)

> **CRÍTICO PARA APROBACIÓN:** Enviar la extensión con permisos que no se usan en el código es la causa #1 de rechazo bajo la política _Minimum Permissions_.
>
> ⚠️ **ACCIÓN TÉCNICA OBLIGATORIA EN `package.json`:**
> Se deben remover de `package.json` antes de compilar para producción:
>
> - `"bookmarks"` (No se usa; `lib/bookmarks.ts` está vacío).
> - `"downloads"` (No se usa en el código).
> - `"audio"` (No se usa en el código).
> - `"browsingData"` (No se usa; la limpieza se hace vía `chrome.history`).
> - `host_permissions: ["https://*/*"]` (Innecesario: `chrome.tabs.query` y `chrome.tabs.remove` funcionan con el permiso `tabs` sin requerir acceso al contenido web de todos los sitios).

### Single Purpose Description (Propósito único)

> _"FocusSpace is a productivity and digital wellbeing tool designed to eliminate distractions by closing tabs matching user-selected distraction categories, clearing recent browsing history, and providing a local Pomodoro focus timer with task management."_

---

### Permisos Reales y Justificaciones Técnicas

| Permiso             | Justificación estricta para el formulario de Chrome Web Store                                                                                                                        |
| :------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`tabs`**          | Required to read open tab URLs to identify tabs matching user-selected distraction categories and close them when the user clicks 'Clean Session'.                                   |
| **`history`**       | Required to clear browsing history within user-selected time ranges (via `chrome.history.deleteRange`) to remove recent distraction traces and address bar autocomplete suggestions. |
| **`storage`**       | Required to save user preferences locally (enabled categories, custom keywords, whitelisted domains, tasks, and Pomodoro settings) via `@plasmohq/storage`.                          |
| **`alarms`**        | Required to schedule reliable background alarms (`chrome.alarms`) that notify the user when Pomodoro focus and break intervals expire, even when the popup is closed.                |
| **`notifications`** | Required to display system desktop notifications when a Pomodoro focus sprint or rest break completes.                                                                               |

---
